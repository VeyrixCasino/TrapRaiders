# Product families — analog kits (game catalog)

Owner: **lead**. This is a **content bible**, not a cook book.

- **No recipes. No precursor names. No yields. No glassware steps.**
- Each `{…}` cluster is one **kit**. Inside a kit, products are the same mesh family: ring-position / halogen / chain-length / N-swap as a **stamp**. That is the “1–4 chemicals different” rule in *game* terms, not a real-world how-to.
- **Opioids are banned** from this game (too many, too strong, wrecks the loop).
- RCs sit behind the **Flask** door. Street 4-MMC-likes can leak earlier as *finished bricks only*.
- Recolor fills live in the art bible. Names here are **in-world slang + real analog tags** so designers can pick SKUs. Signs and NPC chatter still use invented street names.

Unlock vibe (from CITY / lab contract): Open → Grow → Kitchen → Flask → RC.

---

## How a kit works in Port Rook

| Stamp slot | What the player thinks they swapped | Example |
|---|---|---|
| 1 | Ring **position** (2 / 3 / 4) | 4-MMC → 3-MMC → 2-MMC |
| 2 | Ring **halogen vs alkyl** (Me / Cl / F / Br / MeO) | 4-MMC → 4-CMC → 4-FMC |
| 3 | **Chain length** on the cathinone backbone | α-PVP → α-PHP → α-PiHP |
| 4 | **N-group** (methyl / ethyl / pyrrolidine) | 4-MMC → 4-MEC ; pentedrone → NEP |

**Catalog lists every named SKU that actually circulated.** UI still ships 3–8 headliners per kit. Do not explode into theoretical isomers that never had a bag on a table (no 2C/NBOMe alphabet).

Feel (for AI, NPCs, economy — not a tox lecture):

- **MMC/CMC** — short, talky, redose hell. Powder / crystal.
- **Pyros** — nasty, compulsive, “bath salt” panic. Cheap after Flask. Some are **route-locked** in NPC myth (α-PPP).
- **bk-MDMA** — closer to empathogen than to flakka.
- **Dissos** — hole vs walk-around vs mania. Ket-likes / MXE-likes / PCP-likes / diarylethylamines.
- **2C** — mid psychedelic. NBOMe — blotter, microdose-scale, high fail-state (NPC OD).
- **APB / MAPB** — MDMA cousins, pills or powder.
- **Phenidates / 3-FPM** — “functional” stims; less party, more grind.

Street **reviews** live in the feel-card appendix. They are NPC rumor, not a how-to. No doses. No injection SOP. Route notes are flags (`slam_only`, `vape_fav`, `oral_ok`).

## 1. Stimulants — cathinones (main)

Parent idea: khat’s cathinone → synthetic β-keto amphetamines. EU seizures historically cluster on 4-MMC / 3-MMC / 4-CMC / 3-CMC, methylone/ethylone, pentedrone, α-PVP, MDPV.

### Kit A — MMC (methyl-methcathinone)

Same kit. Stamp = ring position.

```
{ 4-MMC (mephedrone, 4-MMC), 3-MMC, 2-MMC }
```

Headliners. 4-MMC is the famous one; 3-MMC / 2-MMC showed up as “legal” stand-ins after 4-MMC got heat. **This is the tutorial Flask brick.**

### Kit B — CMC (chloro)

Same kit as A except stamp 2 = Cl instead of Me.

```
{ 4-CMC (clephedrone), 3-CMC, 2-CMC }
```

Same loop as MMC in Europe: 4-CMC controlled → 3-CMC flood. Pair kits A+B as one “mephedrone wall” in a trap house:

```
[{4-MMC, 3-MMC, 2-MMC} + {4-CMC, 3-CMC, 2-CMC}]
```

### Kit C — FMC (fluoro) and Kit D — BMC (bromo)

Same wall, rarer SKUs. Keep 2–3 each, not a halogen zoo.

```
{ 4-FMC (flephedrone), 3-FMC, 2-FMC }
{ 4-BMC, 3-BMC }
```

### Kit E — N-ethyl “MEC / Hexen” (chain + N-ethyl)

Stamp 3–4. Still a cathinone, not a pyro.

```
{ 4-MEC, 3-MEC, pentedrone, N-ethylpentedrone (NEP), N-ethylhexedrone (hexen), hexedrone, buphedrone,
  4-EEC, 3-EEC, 4-CEC, 3-CEC, 4-EMC, 3,4-DMMC, mexedrone, N-ethylbuphedrone (NEB), 4-MPD }
```

Play as “longer, dirtier MMC.” Hexen/NEP were big after mephedrone dried up. **NEP is the current mislabel** — bags stamped 3-MMC that last all night and feel cold. CEC/EEC = halogen/ethyl stamps on the same wall. Mexedrone = hyped flop. 3,4-DMMC = old legal-high leftover.

### Kit F — bk-MDMA / methylenedioxy cathinones (empathogen-stims)

Same methylenedioxy stamp as MDMA, but cathinone. **Share art with pressed pills + crystals.**

```
{ methylone (bk-MDMA), ethylone (bk-MDEA), butylone, pentylone, eutylone, N-ethylpentylone (ephylone), dipentylone }
```

Keep **methylone, ethylone, eutylone, ephylone** as the four that NPCs actually ask for. The rest are vendor filler.

### Kit G — 4-MeO / odd ring

One or two SKUs so the wall isn’t empty.

```
{ methedrone (bk-PMMA), 4-MEC already in E }
```

## 2. Stimulants — pyrovalerones (pyrrolidine cathinones)

The “bath salt / flakka / monkey dust” rack. N is a **pyrrolidine ring**; **chain length is the stamp**. Same kit for the whole MD / α-PXP wall. Very compulsive, bad for story NPCs, good for late-game heat.

Old forums / legal-high catalogs (Bluelight, first-wave RC reddit, UK NRG/Ivory Wave era, later STRIDA / EUDA lists) did **not** invent a new family. They walked the **same two columns** carbon by carbon after each ban. That is the “10–15 extra MD α-PXP ones.”

### Chain pairing (one wall, two stamps)

Stamp A = **MD ring on/off**. Stamp B = **carbons on the tail**. Same mesh.

| Tail | α-PXP (no MD) | MD-α-PXP | Old vendor / forensic tags |
|---|---|---|---|
| C3 propion | **α-PPP** | **MDPPP** | 3,4-MD-α-PPP |
| C4 butyro | **α-PBP** | **MDPBP** | 3,4-MD-α-PBP |
| C5 valero | **α-PVP** (flakka) | **MDPV** | Ivory Wave / “bath salt” headliner |
| C6 hexano | **α-PHP** (PV-7) | **MDPHP** | 3,4-MD-α-PHP |
| iso-C6 | **α-PiHP** | **MDPiHP** | MDPHPP; isomer of the hexano pair |
| C7 heptano | **α-PEP** (PV-8, α-PHPP) | **MDPEP** (MD-PV8) | 3,4-MD-α-PEP; later EU/US seizures |
| C8 octano | **α-POP** (PV-9) | **MDPOP** | MD-PV9; rare, vendor-only |
| C9 | **α-PNP** (PV-10) | — | skip; almost nobody stocked it |

Player-facing cluster (your original plus the old missing homologs):

```
[{ MDPPP, MDPBP, MDPV, MDPHP, MDPiHP, MDPEP }
 + { α-PPP, α-PBP, α-PVP, α-PHP, α-PiHP, α-PEP/PV-8, α-POP/PV-9 }]
```

That is **13 named SKUs** on two stamps. **MDPOP** is the 14th if you want a dusty crate. Do not add PV-10 to the board.

### Kit H — MD-pyros (methylenedioxy + pyrrolidine)

Full old-to-new homolog run. Same kit as I, MD stamp on.

```
{ MDPPP, MDPBP, MDPV, MDPHP, MDPiHP, MDPEP }
```

Street / vendor aliases (signs, not extra molecules):

- MDPV = the 2010 bath-salt panic; “Ivory Wave” bags
- MDPHP = the C6 replacement after MDPV heat
- MDPiHP = isohexyl twin of MDPHP (forensics keep mixing the two — **separate SKUs**)
- MDPEP / MD-PV8 = C7, later wave (Sweden ~2019, CFSRE monograph as Methylenedioxy-PV8)
- MDPPP / MDPBP = the short ones old catalogs listed next to MDPV (Bluelight treated them as the C3/C4 MDPV cousins)

Ship as **six**. MDPOP stays grayed.

MD-adjacent copycats from the same 2014 “MDPV is gone, now what” threads — **not a new kit**, one-off stamps on H:

```
{ 2,3-MDPV, 5-DBFPV (3-desoxy-MDPV) }
```

2,3-MDPV = ring-position isomer of MDPV (forum bait, barely a product). **5-DBFPV** = dihydrobenzofuran stand-in that actually got sold and has a Bluelight thread; treat as the “almost-MD” pyro.

### Kit I — α-pyros (no methylenedioxy)

```
{ α-PPP, α-PBP, α-PVP (flakka / gravel), α-PHP (PV-7), α-PiHP, α-PEP (PV-8), α-POP (PV-9) }
```

α-PCYP (the **seized bag is cyclohexyl**, not cyclopentyl) is one extra late stamp if you want a weird vendor bottle. Homework stim on the pipe despite beating flakka on DAT. The cyclopentyl analog is paper-only. Not a wall.

Plus the popular **ring** stamps on the PVP / PHP / PiHP end (do not list every 2-/3-/4-Me/F):

```
{ 4F-α-PVP, 4Cl-α-PVP, 4-Me-α-PVP, 4F-α-PHP, 4F-PV8,
  3F-α-PiHP, 4F-α-PiHP, 2-Me-α-PiHP, 3-Me-α-PiHP, 4-Me-α-PiHP }
```

α-PiHP was a top EU pyro seizure around 2023; 2-/3-/4-Me-α-PiHP showed up in Swedish casework. STRIDA (Sweden, 2010s) already had the earlier copycats in blood: **α-PBP, MDPHP, 4F-α-PVP, α-PHP, PV-8, 4F-PV8, 4Cl-α-PVP, 4F-α-PHP, α-PPP, 4-MePPP, α-PVT**. That is the “old reddit” board, not theory.

**Cap the methyl/fluoro PiHP board at those six**, not a 3×4 isomer grid in the UI.

### Kit I-old — 4-methyl “German / Centroton” wall

Same pyro kit, stamp = **4-Me on the ring**, walk the tail. This is the *actual* parent series (pyrovalerone was a 1960s medicine name). Old catalogs listed these next to MDPPP.

```
{ 4-MePPP (MPPP), MPBP, pyrovalerone (4-Me-α-PVP / Centroton), MPHP (PV-4) }
```

Four SKUs. MOPPP (4-MeO-α-PPP) is the one methoxy cousin if the crate needs a fifth.

### Kit J — odd pyros (not MD, not plain phenyl)

```
{ naphyrone (NRG-1 / O-2482), α-PVT (thienyl), α-PBT, TH-PVP, 5-PPDI, 5-BPDI }
```

Easter-egg vendor SKUs. **Naphyrone** is the one NPCs remember (UK “NRG-1” packets, often actually MDPV in the bag). α-PVT / α-PBT = sulfur-ring. TH-PVP = tetralin. 5-PPDI / 5-BPDI = indane. Do not build a third wall — one dusty shelf.

## 3. Dissociatives — get the weird ones

Same hole fantasy. Four kits, not three. Stamp = ring (3-MeO / 3-HO / 3-Me / 3-Cl / 3-F / 4-MeO) and N-group (methyl / ethyl / propyl / pyrrolidine / morpholine) and 2-oxo on/off.

### Kit K — ketamine-likes (2-oxo, short-to-mid)

```
{ ketamine, DCK (deschloroketamine), 2F-DCK (2-FDCK), 2F-NENDCK (CanKet),
  FXE (fluoroxetamine), HXE (hydroxetamine), NENK (N-ethylnorketamine / “ethketamine”),
  2-MeO-ketamine, 2-BDCK (2-bromo-DCK), tiletamine }
```

DCK = ket minus ring Cl, longer. 2F-DCK = F instead of Cl — **batch lottery**. 2F-NENDCK = later N-ethyl fluoro after 2F-DCK dried. FXE sits between ket and MXE. HXE = the warm weak one. NENK / 2-MeO-ket / 2-BDCK / tiletamine = old or vet-shelf.

### Kit L — MXE-likes (3-sub + 2-oxo-PCE)

```
{ MXE (methoxetamine, 3-MeO-2-oxo-PCE), DMXE (deoxymethoxetamine, 3-Me-2-oxo-PCE),
  MXPr (methoxpropamine), MXiPr (methoxisopropamine), HXE already in K }
```

Player cluster:

```
{ MXE, DMXE, MXPr, MXiPr }
```

“3DMXE” in chatter = **DMXE / 3-Me** marketing. MXE is the one old heads will not shut up about.

### Kit M — PCP family (walk-around mania)

```
{ PCP, 3-MeO-PCP, 3-HO-PCP, 3-Me-PCP, 3-Cl-PCP, 3-F-PCP, 4-MeO-PCP, 3-MeO-PCPy, 3-Me-PCPy }
```

3-MeO-PCP = “god mode” / mania. 3-HO-PCP = warm-numb myth. 3-Me-PCP = the functional one people actually finish a sentence on. 4-MeO-PCP = first RC PCP, weaker. 3-Cl / 3-F = later stamps. PCPy = pyrrolidine N-swap (rolicyclidine family).

### Kit N — PCE / odd N-group

```
{ PCE (eticyclidine), 3-MeO-PCE, 3-HO-PCE, 3-Me-PCE, O-PCE (2-oxo-PCE),
  3-MeO-PCPr, PCPr, 3-MeO-PCMo, TCP (tenocyclidine), 3,4-MD-PCP }
```

O-PCE sits between ket and PCE — clean, fiendish, “air sucked out of the room.” 3-MeO-PCE = stimulating, mania-prone. 3-HO-PCE = “just disso,” no magic. PCMo = morpholine, weak. TCP = thiophene Parke-Davis leftover.

### Kit W — diarylethylamines (not arylcyclohexylamines)

Different kit, same “legal ket” era (2013–2016). Long, confusing, steep.

```
{ diphenidine, ephenidine, MXP (methoxphenidine / 2-MXP), fluorolintane }
```

MXP was sold as the MXE replacement and mostly disappointed. Ephenidine is the one trip reports call “cosmic / forced.” Diphenidine = steep and dumb. One shelf, four bottles.

Street rack:

```
[ { MXE, DMXE, MXPr } + { DCK, 2F-DCK, 2F-NENDCK, FXE, HXE }
  + { PCP, 3-MeO-PCP, 3-HO-PCP, 3-Me-PCP }
  + { PCE, 3-MeO-PCE, O-PCE } + { diphenidine, ephenidine, MXP } ]
```

## 5. Psychedelic phenethylamines (short lists)

### Kit Q — 2C (Shulgin 2C-x)

Only the ones people actually say out loud:

```
{ 2C-B, 2C-C, 2C-I, 2C-E, 2C-D, 2C-P, 2C-T-2, 2C-T-7 }
```

**2C-B** is the star (also the fake “tusi” name). 2C-I / 2C-C are the halogen cousins. 2C-E is the “heavier” one. **2C-P** is the long one people warn about. 2C-T-2 / 2C-T-7 are the two sulfur names that got famous — T-7 is the high fail-state. **That is the whole 2C board. No alphabet.**

### Kit R — NBOMe (2C + N-benzyl)

Same three that got the DEA “N-bomb / Smiles” sheet. Microgram blotter. **High NPC death chance if sold as acid.**

```
{ 25I-NBOMe, 25B-NBOMe, 25C-NBOMe }
```

That maps 2C-I / 2C-B / 2C-C → NBOMe. Do **not** add 25N, 25D, 25E, etc.

### Kit S — DOx (amphetamines, not 2C)

Three is enough:

```
{ DOM (STP), DOB, DOI, DOC }
```

Long, heavy. Vendor / festival NPC only. DOC is the fourth name that actually got sold. Bromo-DragonFLY is a **one-off scare SKU** (high `OD` flag), not a family.
