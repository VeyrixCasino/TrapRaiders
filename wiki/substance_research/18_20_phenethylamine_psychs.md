# Assignments 18–20 — Phenethylamine psychedelics (Kits Q / R / S)

Game catalog for Bellhaven / Port Rook. **Not a cook book.** No recipes, no precursors, no milligram how-to, no injection SOP. Scores are unitless **0–100 or `null`**. Unknown stays `null`, never `0`.

**Psych style:** The hit is **enjoyment / euphoria** first. **Rush** is usually low or unknown (these are not coke-shaped). **Compulsiveness** is usually low unless a thread actually shows a redose loop. Negatives sit **below**: duration hang, anxiety / freakout, and — for NBOMe — **death if sold as acid**.

Inferences the house already owns:

- **2C-B** is the star.
- **2C-P** — don’t start here.
- **25I** — never label as LSD.

UI still ships the short Kit Q / R / S boards from `wiki/product_families.md`. This file **lists every substantiated name**. Headliner = bag that actually sat on a table and has a feel. Museum = documented (PiHKAL, paper, forensic, vendor) but not a v1 SKU.

## How to read a card

| Axis | Meaning here |
|---|---|
| **Enjoyment** | Would an NPC buy the night again? |
| **Euphoria** | Lift / candy / well-being during the peak |
| **Rush** | Immediate slam-in. Psychedelics almost never have one. |
| **Compulsiveness** | Envelope-emptying, not “I liked it.” |
| **Anxiety / freakout** | Come-up dread, looping, festival-wrong |
| **Aftereffects** | Duration hang, next-day sludge — **not** a half-life |
| **Cardiovascular** | Body-load / vasoconstriction rumor, not a tox lecture |

**Receptor data ≠ human reports.** Especially assignment 19: 5-HT2A binding is a lab fact; “N-bomb killed someone who thought it was acid” is a street fact. Do not merge them.

**Out of this file:** LSD / 1P / AL-LAD (assignment 24). Tryptamines (21–23). MDMA / MDA / APB (11–12). Mescaline / escaline / proscaline as a cactus wall (leave for 30 if needed). Opioids: banned.

# 18 — Entire documented 2C family (Kit Q)

2C = 2,5-dimethoxyphenethylamines. The letter is the **4-position stamp** (B = bromo, C = chloro, I = iodo, E = ethyl, P = propyl, T = thio…). Shulgin coined the name so they are not the three-carbon DOx amps. Most are **5-HT2A partial agonists** in the lab; they are **not** monoamine releasers like MDMA (Rickli / Eshleman / Luethi). Human feel is a mid psychedelic with optional candy — not a roll, not acid.

**tusi / pink cocaine** is a **color**, usually ketamine ± extras. It is not 2C-B. Flag `mislabel` on the *name*, not a second molecule.

## 19 — Keep these two stacks apart

### Receptor / lab (not a trip report)

- N-benzyl boosts **5-HT2A** affinity and functional potency vs the parent 2C. Rickli et al. 2015; Poulie / Jensen / Halberstadt / Kristensen 2020 *DARK Classics*.
- Used as **research ligands**: 25I-NBOMe ≈ Cimbi-5; 25B-NBOMe ≈ Cimbi-36 (PET). That is a scanner story, not a party story.
- Generally **selective 5-HT2** agonists; not MDMA-type releasers (Rickli). Some rodent work shows unexpected **reinforcement / DA** for 25B and 25N — **animal**, do not turn it into a compulsiveness score unless humans said so.
- **25CN-NBOH** is a highly 2A-selective tool compound (Hansen). Almost no recreational file.
- Conventional NBOMes are treated as **orally weak** (first-pass). That is pharmacokinetics, not a recipe. Street use is blotter / mouth — NPC flag only, no SOP.
- NBOH can **fall apart in hot GC** and get mis-ID’d as the parent 2C (Arantes 2017 on 25I-NBOH). Lab trap, not a new SKU.

### Human / street (not a Ki table)

- No controlled human psychopharmacology as of the 2020 review (Poulie). Feel is **forums + ED + medical examiners**.
- **25I / 25B / 25C** dominate NFLIS / case reports. Peak US reports ~2014 (DEA).
- Sold as **LSD / blotter acid**. Bitter tab, numb mouth — the discriminant in the papers. Users who “know acid” take more tabs. Seizures, agitation, hyperthermia, vasoconstriction, trauma, death (Poklis blotter paper; Indiana 25B/25I fatalities; Zawilska 2020).
- Brazil later found **NBOH** blotters taking the local “acid” slot (25I then 25B/25C/25E-NBOH).
- Compulsiveness stays **low-to-mid**. People do not fiend these like pyros. The kill-state is **mislabel + potency + panic**, not a binge loop.

# 20 — DOx + Bromo-DragonFLY + related long psychedelic amps (Kit S)

DOx = **α-methyl** (amphetamine) cousins of the 2Cs. Same 2,5-dimethoxy + 4-stamp. Longer, heavier, more vasoconstriction rumor. Blotter-capable. Delayed onset has caused **redose-as-acid** disasters — `freakout`, sometimes `OD`, sometimes `mislabel`.

Kit S UI is four names plus one scare bottle. This file lists the documented rest.

## Gaps

- Almost no modern controlled 2C human data except 2C-B (and even that is small).
- NBOMe human pharmacology is **absent**; scores are tox + forum.
- 2C-C / 2C-P rodent reinforcement should not be silently copied into compulsiveness.
- tusi keeps poisoning 2C-B identity.
- NBOH GC→2C mis-ID will keep confusing labs and NPCs.
