# Assignments 21–23 — Tryptamines

Game catalog for Bellhaven / Port Rook. **Not a cook book.** No recipes, no precursors, no milligram how-to, no injection SOP. Scores are unitless **0–100 or `null`**. Unknown stays `null`, never `0`.

**Psych style / user override:** The hit is **enjoyment / euphoria** first. **Rush** only if it actually launches — **5-MeO-DMT is a freight train, not a pyro rush.** **Compulsiveness** is usually low. Negatives sit **below**.

Do not clone effects from names. 4-AcO is not automatically 4-HO. 5-MeO-DMT is not strong DMT. DiPT is ears, not a visual with a side effect.

UI still ships the tiny festival list in `wiki/product_families.md`. This file **lists every documented name**. Headliner = bag that sat on a table and has a feel. Museum = documented but not a v1 SKU.

## How to read a card

| Axis | Meaning here |
|---|---|
| **Enjoyment** | Would an NPC buy the night again? |
| **Euphoria** | Lift / bliss during the peak — not the same as enjoyment |
| **Rush** | Launch/force. Almost never a cathinone slam. Null if it's just a come-up. |
| **Compulsiveness** | Envelope-emptying. Family-low. |
| **Anxiety** | Dread, looping, wrong room |
| **Aftereffects** | Hang, ear-residue, next-day flat — **not** a half-life |
| **Cardiovascular** | Chest/BP rumor, especially 5-MeO |

**v1 street rack:** **DMT, 4-AcO-DMT, 4-HO-MET, 4-HO-MiPT, 5-MeO-DMT, 5-MeO-MiPT**, plus fruit as **psilocybin**. Foxy and DiPT are rumor SKUs. Ibogaine is a clinic crate, not a festival bin.
